# PDF 악보 뷰어 · 가사 프롬프터

## 사용하는 방법

- 밴드 참여곡의 곡 화면 → **악보 보기** → 등록한 PDF 선택: 전용 뷰어에서 이전/다음 페이지, 페이지 번호 이동, 확대를 사용할 수 있습니다. 키보드 좌우 화살표와 Page Up/Down도 지원합니다. 모바일에서는 기기 방향에 맞춰 배치됩니다.
- 곡 화면 → **가사 보기**: 가사 편집 후 **가사 적용**을 누르면 밴드의 곡 문서로 공유됩니다. 일반 곡 문서와 같은 서버 동기화 경로를 사용하므로 화면 상단의 동기화 상태를 확인하세요. 자동 스크롤, 일시 정지, 처음으로, 글자 크기와 속도 설정을 지원합니다. 휠·터치로 직접 이동하면 자동 스크롤이 멈춥니다. 글자 크기와 속도는 사용자별로 현재 브라우저에 보관됩니다. 전체 화면은 브라우저가 지원하는 경우에만 동작합니다.
- 편집 가능한 악보는 **악보 프로젝트 열기 → 프로젝트 선택 → 악보 편집 → 파일 · 내보내기 → MusicXML 가져오기**에서 불러올 수 있습니다. PDF는 보기 용도로 등록하며, 편집 가능한 악보로 자동 변환하는 기능은 제공하지 않습니다.

카메라 제스처, 녹음 기준 가사 시점 등록, 공연 소리 자동 동기화는 현재 구현 범위에 포함하지 않습니다.

## 저장과 배포

- 가사는 기존 밴드 문서 `song/<songId>/lyrics`의 문자열로 저장합니다(최대 50,000자). **DB 테이블·컬럼 변경과 마이그레이션은 없습니다.** 운영 서버에는 새 문서 키를 허용하는 서버 코드도 함께 배포해야 합니다.
- PDF 뷰어는 Mozilla PDF.js를 사용합니다. 저장소가 외부 파일 다운로드를 허용하도록 기존 파일 저장소의 CORS 설정이 필요합니다.
- PDF 뷰어와 가사 프롬프터에는 별도 악보 인식 프로그램 설치가 필요하지 않습니다.

저장소 루트에서 의존성을 설치하고 빌드한 뒤 기존 방식으로 서버와 웹을 배포·재시작하세요.

```powershell
npm ci
npm run build:server
npm run build
```
