# PDF 마디 경계 저장

마디 분석 화면에서 **마디 정보 저장**을 누르면 기존 `personal_documents` 테이블에 저장합니다. DB 스키마 변경 및 마이그레이션 명령은 필요하지 않습니다.

- 키: `pdf-measures:<PDF SHA-256>:<악보 종류>`
- 사용자별로 분리되며 PDF 파일명과 무관하게 동일한 PDF를 다시 준비하면 저장된 경계를 불러옵니다.
- 페이지를 잘라 분석한 경우 잘라낸 PDF 기준입니다. 같은 페이지 선택으로 준비해야 재사용됩니다.
- 임시 작업 삭제나 서버 재시작은 저장된 경계를 삭제하지 않습니다.
- PDF 원본과 음표 분석 결과는 이 문서에 저장하지 않습니다.
- 같은 파트·페이지·줄의 위아래 경계를 공유합니다. 경계 조정 시 인접 마디의 가로 경계도 함께 이동합니다.
