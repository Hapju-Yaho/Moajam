# 세션 트랙과 악보 편집

## 세션별 트랙

연습실에서 곡을 선택하거나 곡 상세의 연습 탭에서 사용한다. 합주 기록에서도 같은 트랙 입력기를 사용하며, 저장 범위는 기존처럼 밴드·곡 또는 날짜별 합주로 분리된다.

- 추가 전 세션 선택: 보컬, 기타, 베이스, 드럼, 키보드, 기타 악기, 전체 합주/원곡, 미지정.
- 파일 업로드·마이크 녹음·곡 자료 가져오기에 선택한 세션을 기록한다. 파일당 100MB 이하이며 빈 파일과 오디오가 아닌 파일을 거부한다.
- 등록 후 세션 변경이 가능하다. 기존 트랙의 음원과 믹서 설정을 유지하고, 세션이 없는 기존 기록은 미지정으로 표시한다.
- 웹에서 세션별 표시 필터를 제공한다. 필터는 목록에만 적용하며, 재생 믹스는 기존 음소거·솔로·볼륨 설정을 따른다.
- 서버 연결 시 개인 문서 및 파일 API로 저장하고, 데모에서는 브라우저/기기 저장소를 사용한다. 기본 비공개이며 기존 밴드 공개 버튼은 별도로 유지한다.
- 네이티브 앱도 세션 지정과 변경을 저장한다. 여러 트랙 동시 재생은 웹 전용이다.

### 웹 타임라인과 메트로놈

- 고정된 트랙 설정과 가로 스크롤 파형 타임라인, 마디/초 눈금, 재생 커서, 확대·축소, 크게 보기를 제공한다. 파형은 업로드된 오디오를 디코딩해 생성한다.
- 빈 트랙 추가, 여러 음원 업로드, 클립 드래그/방향키 이동, 박자 스냅, 음소거·솔로·트랙 및 전체 볼륨, A/B 반복을 지원한다. 트랙을 지정해 파일이나 녹음을 추가하면 해당 트랙의 클립으로 추가하며, 기존 음원은 보존한다.
- 새 파일 추가 버튼을 상단과 타임라인 도구 모음에 강조 표시한다. 클립은 좌우 드래그로 시간을 바꾸고 위아래 드래그 또는 방향키로 트랙 사이를 이동한다. 수직으로만 이동하면 시작 시간은 유지한다. 겹친 클립도 보이도록 트랙 안에서 높이를 나눠 표시하며 함께 재생한다.
- `클립 붙이기`가 켜져 있으면 드래그 중 보이는 다른 클립의 시작·끝에서 화면상 10px 이내로 접근한 경계를 자동 정렬한다. 가까운 클립 경계는 박자 맞춤보다 우선하며, 안내선과 대상 클립 강조로 붙는 위치를 표시한다. Alt를 누른 채 드래그하면 클립·박자 맞춤을 일시 해제한다.
- 클립을 선택하고 클립 내부에 커서를 놓은 뒤 `커서에서 자르기` 또는 S 키로 나눈다. 원본 파일을 수정하지 않고 시작 구간과 길이를 저장하므로, 여러 번 자르고 이동해도 각 조각의 원본 구간을 재생한다. 내려받기와 밴드 공개는 버튼에 표시된 대로 원본 파일을 사용한다.
- 기존 단일 음원 트랙은 여러 클립 형식으로 읽어 들인다. 클립 구조와 편집 구간을 함께 저장하고, 네이티브에서는 각 클립을 개별 재생할 수 있다.
- 메트로놈은 음원과 함께 또는 단독 재생할 수 있다. BPM 30–300, 4/4·3/4·2/4·6/8, 첫 박 강세, 별도 음량, 녹음 전 0·1·2마디 카운트인을 제공한다. BPM은 모든 박자표에서 4분음표 기준이다.
- 클릭은 Web Audio 시계로 미리 예약하며, 정지하면 예약된 클릭과 카운트인을 취소한다. 녹음은 현재 커서에서 시작하고 반주와 함께 진행된다.
- 트랙도 Web Audio 버퍼를 먼저 준비하고 같은 오디오 시계에 시작·종료를 예약한다. 화면 갱신은 커서 표시에만 사용한다. 잘랐다 붙인 경계에 재생 지연이나 별도 페이드를 넣지 않으며, 볼륨·음소거·솔로는 재생을 재시작하지 않고 게인으로 변경한다. 반복 구간은 다음 회차를 미리 예약한다.
- BPM·박자표·카운트인·음량·트랙 배치를 기존 연습 저장 범위에 함께 저장한다. 빈 트랙은 네이티브에서도 보이지만 음원 연결과 타임라인 편집은 웹에서 수행한다.

## 악보 편집

개인 연습실의 악보 편집 버튼은 현재 선택한 곡의 악보로 연결된다. 곡을 선택하지 않았으면 개인 악보를 연다.

- 오선보나 TAB에서 마우스로 박을 드래그하면 현재 파트의 연속 구간을 선택한다. 마디·줄을 넘어 선택할 수 있고, 해당 구간의 모든 줄과 쉼표·빈 박을 포함한다. Shift+클릭 또는 Shift+좌우 방향키로도 범위를 넓히며 Esc로 해제한다.
- 구간 선택 상태에서 길이·쉼표·악센트·스타카토·뮤트·괄호 표기를 함께 변경한다. 주법은 실제 음에만 적용하며, 길이 변경은 뒤 음표 위치를 유지한다. 하나라도 충돌하면 전체 길이 변경을 취소한다. 개별 프렛·가사 입력과 빈 박 삽입은 한 박을 선택했을 때 사용한다.
- 박 삭제·빈 박 삽입·박 순서 변경 시 코드 이름도 해당 음표 안의 상대 위치를 따라 이동한다. 삭제한 구간의 코드는 제거하고, 시작 위치가 달라진 음표의 개별 음원 싱크는 해제한다. 다른 파트와 이동하지 않은 음표의 싱크는 유지한다.
- 상단 복사/붙여넣기 버튼과 Ctrl/Cmd+C·V를 지원한다. 프렛·코드 음·길이·가사·주법과 구간 내 코드 이름의 박 위치를 복사하고, 선택 위치에 삽입하여 기존 뒤 음표와 코드 이름을 함께 이동시킨다. 긴 음표 중간에 바뀌는 코드도 상대 위치를 유지한다. 음원 싱크 표시는 복사하지 않으며 이동한 음표의 개별 싱크는 해제한다. 붙여넣기 한 번은 실행 취소 한 번으로 되돌린다. 파트 사이에서도 복사할 수 있으며 브라우저 클립보드에는 버전이 있는 악보 데이터로 기록한다. 일반 텍스트는 악보로 붙여넣지 않고, 입력칸에서는 원래 텍스트 복사/붙여넣기를 유지한다.

- 웹은 조표·박자표를 설정할 수 있는 오선보·TAB 동시 편집기다. 한 박에 여러 줄의 음을 입력해 코드를 만들 수 있으며 각 파트는 하나의 리듬 성부를 사용한다. 기타 표준·Drop D·4현 베이스 튜닝과 일반 오선보를 제공한다. 튜닝을 변경하면 음높이는 유지하며 운지를 다시 배치한다.
- TAB 줄을 클릭하고 0–24 프렛을 입력한다. 숫자 두 개를 0.9초 안에 누르면 두 자리 프렛이 된다. 좌우 방향키는 박 이동, 위아래는 줄 이동, `[`는 음표를 길게, `]`는 짧게 바꾼다(기존 −/+도 지원). 점(.)은 점음표, R은 쉼표, Space는 파트 재생, Ctrl/Cmd+Z는 실행 취소다. Delete는 선택 줄을 비우고 Shift+Delete는 박 전체를 삭제한다. 입력 영역에 초점이 있을 때만 단축키가 작동하며 텍스트 입력 중에는 작동하지 않는다.
- 빈 칸에서 음표 길이를 고르면 악보를 변경하지 않고 입력 예정 길이만 바꾼다. 주황색 커서 아래에 해당 마디에서 차지할 범위를 밑줄로 표시하며, 미리보기 음표나 길이 글자는 표시하지 않는다. 실제 입력 시 남는 시간은 빈 박으로 보존한다. 기존 음표의 길이를 바꾸면 뒤 음표도 순서대로 이동하며 원래 마디에 유지한다. 박자표와 길이가 맞지 않는 마디는 빨간색으로 표시하지만 재생할 수 있다. 미리보기는 저장·재생·인쇄에 포함하지 않는다.
- 빈 마디와 빈 박을 직접 클릭하거나 방향키로 건너뛰어 입력한다. 줄마다 추가 기호를 표시하지 않고 현재 입력 위치에만 사각 커서를 표시한다. 뒤쪽 박에 입력하면 앞의 빈 박을 무음으로 보존하며, 마지막 음을 지워도 박의 길이는 유지한다. `빈 박 삽입`은 시간을 차지하는 공백을 넣고 R은 명시적인 쉼표를 넣는다. 빈 박은 자동 저장되며 MusicXML에서는 숨겨진 쉼표로 왕복 보존한다.
- 오선보·TAB 클릭 영역은 인접한 박 위치의 중간 지점에서 나눠 마디 폭 전체를 채운다. 넓은 마디의 음표 사이와 양 끝에서도 가까운 박을 선택하며, TAB 줄 사이에도 클릭 공백을 두지 않는다. 보이는 선택 커서는 작게 유지하고, 짧은 음표가 모인 구간에서도 클릭 영역은 겹치지 않는다.
- 선택한 칸을 다시 클릭하면 선택을 해제하고 커서·길이 밑줄을 숨긴다. 다른 칸이나 다른 줄을 클릭하면 선택을 옮긴다. 방향키 이동과 마디 코드 선택은 기존 선택 동작을 유지하며, 선택 해제는 악보 내용을 변경하지 않는다.
- 온음표부터 64분음표까지 지원한다. 4분음표 기준 1/8박은 32분음표(0.125박), 1/16박은 64분음표(0.0625박)이며 `[`·`]`로도 선택한다. 점2분음표부터 점32분음표, 쉼표, 코드 이름·가사·악센트, 박 복사·붙여넣기·순서 변경, 실행 취소·다시 실행을 제공한다. 마디를 넘는 음과 코드는 붙임줄로 표시한다. 재생은 합성 음색으로 코드의 모든 음을 동시에 들려준다.
- 스타카토(S)는 음표에 점을 표시하고 원래 길이의 45%만 소리를 낸다. 고스트/뮤트(X)는 오선보와 TAB에 X를 표시하고 짧은 타격음으로 재생한다. 선택한 빈 칸에서도 바로 입력하며, 기존 음표에서 다시 X를 누르면 원래 프렛으로 돌아온다. Guitar Pro 명칭으로는 데드 노트다. 기존 괄호 표기는 ‘약하게’(O)로 구분하며 같은 음정을 보통 음량의 35%로 재생한다. 뮤트와 괄호 표기는 상호 배타적이고 스타카토와는 함께 적용할 수 있다. 주법은 선택한 박의 코드 전체에 적용하고 박 길이는 유지한다. 저장·실행 취소·MusicXML 왕복 변환을 지원하며, X는 `<notehead>x</notehead>`, 괄호는 [parentheses notehead](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/notehead/)로 보존한다.
- 괄호 고스트 노트가 바로 앞의 같은 줄·같은 음높이로 이어지면 앞 소리와 음량을 유지하며 해당 길이만큼 연장한다. 화음에서도 해당 줄만 이어지고 다른 음은 정상 타격한다. 다른 음높이·다른 줄이거나 쉼표·빈 박·스타카토·데드 노트로 끊어진 경우에는 독립된 약한 음으로 재생한다. 악보 표기는 바꾸지 않으며 기본 음색·가상악기·내 악기 녹음에 동일하게 적용한다. 녹음의 반복 유지가 꺼져 있으면 원본이 끝난 뒤에는 무음이다.
- 재생 시작과 재생 마디 변경 시 현재 마디를 보이는 악보 영역의 세로 가운데에 맞춘다. 같은 마디 안에서는 박마다 스크롤을 움직이지 않는다. 일반 화면은 바깥 스크롤과 악보 내부 스크롤을 순서대로 맞추고, 크게 보기에서는 상단 화면 도구를 제외한 영역을 기준으로 정렬한다.
- 전체 리듬 기호와 BPM 사이에 여백을 두고, 둘째 악보 줄부터 위쪽 여백을 줄인다. 오선보와 TAB의 세로 마딧줄은 각 악보 범위에만 표시한다. PDF는 저장 시 편집 화면의 실제 그리기 너비(확대 비율 반영), 줄 배치, 마디 너비와 기호 글꼴을 공유하며 A4에 맞춰 비례 축소하고 줄 단위로 페이지를 나눈다. 제목은 화면처럼 가운데 정렬하고, 선택 표시와 재생 커서는 출력하지 않는다.
- `음표 연결`의 해머링(H)·풀링(P)·슬라이드(J)·붙임줄(T)은 첫 음표에서 다음 음표로 적용한다. 이어지는 두 박을 범위 선택해도 된다. 같은 버튼/단축키를 다시 누르거나 `연결 해제`로 제거하며, 기존 스타카토 단축키 S는 유지한다. 해머링은 같은 줄의 낮은 단음→높은 단음, 풀링은 높은 단음→낮은 단음, 슬라이드는 같은 줄의 서로 다른 단음을 연결한다. 붙임줄은 같은 높이의 음 또는 같은 음정들로 구성된 코드 전체를 연결한다. 현재 코드 중 일부 줄에만 연결 주법을 적용하는 편집은 지원하지 않는다.
- 연결은 오선보와 TAB에 표시하고 마디·줄 경계를 넘어 이어진다. 붙임줄의 뒤 TAB 숫자는 괄호로 표시한다. 실제 음표는 각각 편집할 수 있으며, 붙임줄 재생은 다시 타격하지 않고 지속한다. 해머링·풀링은 음높이를 연결 지점에서 바꾸고 슬라이드는 앞 음의 끝부분에서 목표 음으로 미끄러진다. 기본 합성 음색으로 재생하며 실제 기타 샘플 음색은 아니다. 중간 선택 재생도 남은 연결 구간을 따른다.
- 쉼표·빈 박·뮤트·스타카토는 연결할 수 없다. 연결된 음표의 삭제·이동·길이·프렛 편집으로 연결 조건이 깨지면 연결을 해제한다. 실행 취소로 복원 가능하며 두 음을 함께 복사하면 붙여넣은 음 사이로 연결을 복원한다. 저장과 MusicXML에서 해머링·풀링·슬라이드·직접 붙임줄을 보존한다. 앱에서 직접 만든 붙임줄은 재가져오기 시 두 음표를 유지하고, 외부 MusicXML의 일반 붙임줄은 기존처럼 긴 음표로 합친다.
- 해머링·풀링·슬라이드는 음표 중심에서 중심으로 잇는 곡선과 H·P·S로 표시한다(슬라이드 단축키는 J 유지). 이음줄과 연결 곡선은 음표·TAB 숫자 가까이에 놓고 끝은 가늘게, 가운데는 조금 두껍게 그린다. 화면과 PDF에 같은 모양을 적용한다.
- `지판 슬라이드`는 같은 줄의 서로 다른 두 음을 물결선으로 연결한다. 첫 음이나 연속된 두 음을 선택해 적용하며, 기존 S 곡선 슬라이드와 별도로 선택할 수 있다. `슬라이드 아웃 ↗ / ↘`는 선택한 단음 끝에서 위·아래로 미끄러지는 마무리 주법이다. 같은 버튼으로 해제하며, 다음 음 연결과 동시에 적용하지 않는다. 재생은 마지막 절반(최대 0.2초)에 7반음 이동하고 원래 박자 끝에서 종료한다. 화면·PDF·악보 파일·복사에 보존되며 MusicXML에는 glissando, doit, falloff로 기록한다.
- 드래그(또는 Shift+방향키)로 구간을 선택하고 `선택 구간 반복`을 체크하면 Space와 재생 버튼으로 해당 구간을 반복한다. 마지막 음·쉼표의 길이까지 포함하고 구간 밖의 도돌이표로 이동하지 않는다. 리듬 느낌과 반주 음원도 같은 구간에 맞춰 반복하며 Space를 다시 누르면 정지한다. 체크 해제 시 일반 재생으로 돌아가고 `처음부터`는 전체 악보를 한 번 재생한다. 반복 설정은 편집 중에만 유지한다.
- `함께 재생할 음원`의 반주 종류에서 `유튜브 영상`을 선택해 주소를 붙여넣거나 `이 곡 영상 불러오기`로 참여 곡에 등록된 영상을 가져올 수 있다. 공식 IFrame Player API를 사용하며 별도 API 키나 영상 다운로드가 필요 없다. 영상 ID·반주 종류·음량·첫 박 위치는 개인/밴드 악보 및 `.moajam` 파일에 저장된다. 파일 음원과 영상 중 선택한 한 쪽만 함께 재생한다.
- 유튜브도 Space/재생/정지, 선택 위치, 도돌이표 및 구간 반복에 따라 이동한다. `현재 영상 위치를 첫 박으로` 또는 초 입력으로 전주 길이를 맞춘다. 자동 재생 차단 시 영상에서 먼저 재생한 뒤 악보를 재생하도록 안내하고, 외부 재생 제한·삭제·연결 실패를 표시한다. 광고·버퍼링·키프레임 탐색 때문에 파일 음원 수준의 정확한 동기화는 보장하지 않는다. 크게 보기에서도 연결된 영상은 표시한다. 참고: https://developers.google.com/youtube/iframe_api_reference
- 상단 재생 버튼 옆에서 BPM을 30–300 정수로 설정한다. Enter 또는 입력 칸을 벗어나면 적용·저장하며, 빈 값과 Escape는 이전 값을 유지한다. 악보 첫 줄의 왼쪽 위, 첫 마디 앞에 `♩ = BPM`을 표시하며 인쇄에도 포함한다. 재생 중에는 BPM 입력을 잠근다. 악보 설정에서 제목·파트와 MusicXML을 관리한다. 기존 단일 음정 악보도 불러올 수 있으며, 네이티브는 기존 간단 편집 화면을 유지하고 코드 음정을 목록에 표시한다. 네이티브의 음정 적용은 해당 박을 선택한 단일 음정으로 교체한다.
- 코드는 파트별 박 위치에 저장한다. 마디 위의 1~4박 위치를 클릭하거나 상단 `코드 위치`에서 박을 고르면 해당 위치의 코드를 편집한다. 예를 들어 2마디 1박 Am과 3박 G를 동시에 표시할 수 있다. 세분된 박의 음표를 선택하면 그 위치에도 입력할 수 있다. 긴 음표 중간이나 빈 박에도 최대 40자의 코드 이름을 넣으며 음표 길이와 재생 시간은 유지한다. 기존 마디 코드는 1박, 기존 음표의 박 코드는 그 음표 시작 위치에 표시한다. 한 위치를 지워도 다른 박의 코드는 유지한다. 실행 취소·파트 이름 변경·줄 배치·MusicXML 왕복 보존을 지원하며 MusicXML direction의 offset으로 마디 안 박 위치를 기록한다.
- 파트 삭제는 확인 후 적용하며 실행 취소로 복원할 수 있다. 관련 음원 싱크도 함께 제거한다.
- 웹 오선은 마디별로 표시하고 음표 선택을 마우스와 키보드로 지원한다. 마디를 넘는 음표는 원래 음표 ID를 유지하며 나눠 표시한다.
- 빈 악보는 1마디로 시작하며 `마디 추가`로 빈 마디를 늘릴 수 있다. 기본 줄 배치는 한 줄에 최대 네 마디이고, 마지막 줄의 마디도 좌우 가용 폭을 채운다. 음자리표·TAB·조표·박자표는 줄 시작에 한 번만 표시한다. 실제 음표·가사·코드에 필요한 간격을 확보하고 남은 폭을 마디에 나눠 배분한다. 빈 칸에서 입력 예정 길이만 바꿔도 마디 폭이 늘어나지 않는다. 촘촘한 악보는 음표 사이 간격을 줄여 줄 너비에 맞추고, 마디별 너비 비중을 조절할 수 있다. 인쇄 시에는 줄을 용지 폭에 맞춘다. 짧은 음표는 4분음표 한 박 단위로 빔을 연결하고, 쉼표·빈 박에서 묶음을 끊는다.
- `다음 줄로`는 선택 마디부터 줄을 나누고, `이전 줄로`는 현재 줄의 시작부터 선택 마디까지 이전 줄에 붙인다. 이동한 경계 뒤의 마디는 기존 수동 줄 나눔을 해제하고 한 줄에 최대 네 마디씩 자동으로 다시 채운다. 앞쪽 줄 배치와 음표 순서·박 위치는 유지한다. Page Down / Page Up도 같은 배치 편집이다. 첫 마디 앞에 빈 줄을 만들지 않으며 수동 배치는 한 줄 최대 16마디다. 배치는 파트별로 자동 저장되고 실행 취소 및 `기본 줄 배치`로 되돌릴 수 있다.
- `선택 위치부터`와 Space는 선택한 음표·빈 박부터 재생하고, 선택이 없으면 첫 마디부터 재생한다. `처음부터`는 선택과 관계없이 첫 마디에서 시작한다. 이어진 음표 중간을 선택하면 남은 길이만 재생한다. 마지막으로 입력한 마디의 남은 빈 박까지 진행한 뒤 정지하며, 이미 마디가 꽉 찼으면 추가 마디를 재생하지 않는다. 재생 커서는 음과 빈 박 위를 함께 이동하며, 뒤에 미리 보여주는 미작성 마디는 재생 길이에 포함하지 않는다.
- 악보 재생 음량은 0–100%로 조절하고 음소거를 켜고 끌 수 있다. 재생 중에도 공통 출력 게인을 변경해 재시작 없이 적용하며, 음량은 악보에 저장한다. 기준 음원 플레이어의 음량은 해당 플레이어에서 별도로 조절한다.
- 상단 `음원 추가`에서 MP3·WAV 등 100MB 이하 파일을 연결하면 `악보와 함께 재생`을 켜고 기존 재생 버튼·Space로 함께 들을 수 있다. 음원을 먼저 디코딩한 뒤 악보와 같은 Web Audio 시계에 예약한다. 선택 위치·처음부터 재생·정지·마지막 마디 종료를 공유하며, 음원이 먼저 끝나면 반복하지 않는다. 음원 음량은 악보 음량과 독립적으로 조절하고 재생 중 변경할 수 있다.
- `첫 박의 음원 위치`는 악보 첫 박에 대응하는 음원의 초 위치다. 전주가 5초면 5, 음원이 악보 시작보다 늦게 나오면 음수를 지정한다. 하단 미리 듣기에서 음원 위치를 잡고 `선택 음표와 음원 위치 맞추기`로 계산할 수도 있다. 음원 재생 속도는 바꾸지 않으므로 악보 BPM을 음원에 맞춘다. 파일·파일명·동시 재생 여부·음량·시작 위치는 기존 계정별 비공개 문서에 저장한다. 디코딩 실패 시 기존 연결을 유지한다.
- 웹에서 마디의 남은 박을 쉼표로 채울 수 있다. 악센트·올림표·덧줄·음표 길이를 표시한다.
- 저장은 계정별 개인 문서를 사용한다. 300ms 동안 연속 입력을 묶어 저장하고, 텍스트 입력 종료·화면 이동 시 대기 중인 저장을 시작한다. 이전 저장 응답이 최신 저장 상태를 덮지 않도록 처리한다. 제목·코드·가사의 연속 입력은 입력칸을 벗어날 때까지 실행 취소 한 번으로 묶는다.
- MusicXML 가져오기는 웹에서 곡 전체에 동일한 조표·박자표를 사용하는 단일 성부와 같은 길이의 코드, 최대 16파트·2,000개 박을 지원한다. 파트 ID로 이름을 연결하고 마디 경계의 붙임줄을 하나의 음표 길이로 복원한다. 내보내기는 코드의 각 음정과 줄·프렛을 기록한다. 다성부·꾸밈음·셋잇단음표 외의 잇단음표, Guitar Pro 전용 파일(.gp/.gpx/.gp5), 벤딩·비브라토 등 주법은 아직 지원하지 않는다.
- 외부 MusicXML의 기본 harmony 코드 기호와 슬래시 베이스를 박 위치에 가져온다. 부족한 일반 마디는 숨겨진 쉼표로 채워 다음 마디가 당겨지지 않게 한다. 못갖춘마디는 지정된 길이로 보존한다. 곡 중간 템포 변화·지원하지 않는 코드 구성은 내용을 버리지 않고 오류로 안내한다. 템포는 4분음표 기준의 일정한 정수 BPM 30–300만 허용한다.
- PDF/이미지 자동 악보 인식, 실시간 공동 편집, 영구 버전 복원은 포함하지 않는다. 실행 취소 이력은 현재 편집 세션에서만 유지된다.

`scripts/clip-playback.browser.html`은 Vite 개발 서버에서 열어 실제 OfflineAudioContext로 검사한다. 48kHz 신호의 원본/분할 재생 샘플, 이동한 클립의 재생 구간, 반복 접합부의 무음을 비교한다.

`scripts/score-editor.browser.html`은 브라우저 DOMParser로 MusicXML 코드·붙임줄·튜닝·줄·프렛 왕복 변환과 지원하지 않는 입력의 거부를 검사한다. OfflineAudioContext로 실제 재생 출력의 100%·50%·음소거와 게인 변경도 확인한다.

파트 변경 시 다른 파트 보존, 관련 싱크 정리, 마디 분할, 오선 음높이, 파일 검증, 개인 문서의 순차 저장과 계정 격리를 검사한다.

## 악보 편집 확장 (2026-10-05)

- `악보 크게 보기`는 브라우저 전체화면 요청 없이 악보와 음표·악보 요소 편집 도구만 창 전체로 확장한다. 사이드바·앱 상단 메뉴·파일/음원/파트 관리 기능은 숨긴다. 스크롤 부모의 transform에 갇히지 않도록 popover top layer를 사용하며 편집기를 다시 마운트하지 않는다. `원래 화면` 또는 Esc로 돌아오며, 열린 단축키·마디 설정 창이 있으면 그 창부터 닫는다.
- 악보 위 제목을 클릭하면 입력칸으로 바뀌며 Enter·바깥 클릭으로 저장, Esc로 취소한다. 상단에서는 조표(플랫 7개부터 샵 7개), 박자표(분자 1~16 / 분모 2·4·8·16)를 바꾼다. 조표 변경은 기존 음높이를 보존하고 임시표와 오선 위치를 다시 표시한다. 박자표는 곡 전체에 적용하며 기존 마디 경계는 유지한다.
- 음표 길이·점음표를 변경하면 뒤 음표를 삭제하지 않고 순서대로 이동한다. 마디별 실제 길이를 별도로 저장해 다음 마디의 음표를 원래 마디에 유지한다. 입력된 음표·명시적 쉼표의 합 또는 마디 길이가 박자표와 다르면 붉은 테두리로 표시한다. 완전히 빈 마디에는 오류 표시를 하지 않는다. 박자 불일치는 재생을 막지 않으며 실제 길이를 따라 재생한다.
- 마디 우클릭 메뉴는 마우스의 화면 좌표에 표시하고 화면 가장자리에서만 실제 메뉴 크기만큼 안으로 조정한다. 마디 우클릭 또는 `마디 설정`에서 너비 비중을 10~500 정수로 입력한다(기본 100). 같은 줄의 총 너비·마디 수를 유지하면서 비중에 따라 다른 마디 너비도 조절한다. Enter 또는 입력 종료 시 적용된다. 줄 너비 균등/자동 배분은 해당 줄의 개별 비중도 초기화한다.
- `이음줄(슬러)` 또는 L은 첫 음부터 다음 음, 혹은 선택한 여러 음 전체를 묶는다. 다시 누르면 해제한다. 기존 동일 음높이의 붙임줄(T)과 독립적이며, 이음줄 안의 음정과 박 길이는 각각 유지해 재생한다. 선택 구간에 쉼표·빈 박이 있으면 안내한다. 오선보와 TAB 양쪽에 표시하며 마디·줄 경계, 전체 구간 복사, 실행 취소와 파일 저장을 지원한다.
- L로 연결할 때 앞 음과 같은 음높이·같은 줄의 뒤 음은 자동으로 고스트 노트 `( )`가 되어 끊김 없이 이어진다. 코드에서는 일치하는 음만 바꾸며, 이음줄을 해제해도 적용된 고스트 노트는 유지한다(고스트 노트 버튼으로 별도 해제 가능).
- 마디 설정에서 겹세로선과 도돌이표를 설정한다. 두 표시는 오선보와 TAB 양쪽에 적용하며, 겹세로선 자체는 재생 순서를 바꾸지 않는다. 도돌이표 시작/끝과 총 재생 횟수(2~8회)를 정한다. 반복은 모든 파트에 적용하며 선택 위치부터 재생할 때도 반복 시작 위치를 기억한다. 반복 시 악보 재생 커서와 연결 음원도 해당 위치로 돌아간다. 현재는 순차적인 단순 반복 구간을 지원하며 1·2번 괄호와 D.C./D.S.는 포함하지 않는다.
- `셋잇단음표 3`은 같은 길이의 이어지는 세 음표·쉼표를 3:2 길이로 전환한다. 첫 음만 선택하면 다음 두 음을 포함하고, 범위 선택 시에는 세 음을 선택한다. 다시 누르면 원래 길이로 돌아온다. 빈 칸에서는 셋잇단음표 입력 모드를 켜고 길이를 선택해 입력한다. 오선·TAB에 괄호와 3을 표시하며 실제 재생 길이, 실행 취소·복사·파일·MusicXML 왕복에 적용한다. 내부 시간 눈금은 4분음표당 48틱이며 누적 위치를 정수 틱으로 정규화한다. 기존 악보의 박 단위 값은 바뀌지 않는다.
- 조표 기호 간격을 10px에서 7px로 줄인다.
- 새 설정은 개인·밴드 악보와 `.moajam` 파일에 보존된다. MusicXML에도 조표·박자표·이음줄·도돌이표·마디 너비·불일치 마디 길이를 기록한다. 불일치 마디는 `implicit` 마디로 왕복 보존하며, 곡 중간 조표·박자표 변경과 파트마다 다른 반복 표시는 가져올 때 명시적으로 거부한다. PDF는 같은 악보 렌더러를 사용한다.
- 검증: 기존 Node 악보 테스트와 `scripts/score-editor.browser.html`(MusicXML 왕복·OfflineAudioContext)을 사용한다. `scripts/score-ui.browser.html`은 메모리에만 테스트 악보를 만들어 화면 확장·길이 편집·마디 설정을 확인하며 사용자 저장 데이터를 변경하지 않는다.

MusicXML 도돌이표의 방향과 `times`는 [W3C MusicXML repeat 명세](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/repeat/)를 따른다.

셋잇단음표는 [MusicXML time-modification](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/time-modification/)의 actual-notes=3 / normal-notes=2, 겹세로선은 [bar-style](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/bar-style/)의 light-light로 저장한다.

### 곡 전체 리듬과 짧은 마디 입력

- `곡 전체 리듬`에서 없음, 8분·16분 셋잇단 느낌(2:1), 점음표 느낌(3:1), 스코티시 느낌(1:3)을 고른다. BPM 위에 `음표 = 음표` 형태의 비율 표기를 표시하며, 없음이면 공란이다. 악보에 적힌 음표 길이와 마디 합계는 그대로 두고 재생 시 박의 앞·뒤 절반을 선택한 비율로 나눈다. 엇박에서 긴 음이 시작하거나 쉼표가 섞여도 적용한다. 명시적인 셋잇단음표·점음표가 걸친 박은 다시 변환하지 않는다. 선택 재생·도돌이표·커서는 같은 타이밍 변환을 사용하며, 연결된 원본 음원은 변형하지 않는다.
- 이 설정은 개인·밴드 저장, 악보 파일, PDF 표시와 MusicXML 왕복에 포함된다. MusicXML은 [W3C swing 명세](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/swing/)의 first/second와 swing-type을 사용한다. 중간에 바뀌는 리듬 느낌은 가져오기를 거부한다.
- 선택 중인 마디는 박자가 부족하거나 넘쳐도 붉은 표시를 숨기며, 선택을 옮기면 경고를 다시 표시한다. 음표 기둥은 오선 가운데 줄 기준으로 자동 결정하며 코드·빔으로 묶인 음표들은 방향을 공유한다.
- 마디에서는 기존 음표·쉼표와 첫 빈 입력 위치만 선택할 수 있다. 첫 빈 박에 방향키로 이동할 때만 입력 칸을 표시하고 다른 마디로 이동하면 뒤쪽 빈 칸은 숨긴다. 빈 마디는 클릭해 첫 박부터 입력한다. 입력 위치를 뒤로 계속 이동해서 여러 빈 박을 만드는 동작은 하지 않는다. 숨긴 빈 구간의 무음과 다른 마디의 위치는 보존하며 `쉼표로 마디 채우기`는 선택한 마디를 채운다.
- 재생 위치는 정수 박으로 표시하고 고정 너비·숫자 고정폭을 사용해 소수점이나 마디 번호 자릿수 때문에 도구줄이 흔들리지 않게 한다. 편집 위치는 소수 셋째 자리까지 표시한다. 악보 커서와 소리의 정밀도는 유지한다.
- 상단 `마디 삽입`은 선택 마디 앞에 새 마디를 넣고, `마디 삭제`는 선택 마디를 제거한다. 우클릭 메뉴에는 앞·뒤 삽입과 삭제가 있다. 모든 파트의 마디와 코드·너비·불규칙 길이·도돌이표·겹세로선 위치를 함께 이동하며 한 번의 실행 취소로 되돌린다. 마지막 마디를 삭제해도 입력 가능한 빈 악보 한 마디는 남는다.
- 쉼표에서 Delete/Backspace를 누르면 그 길이를 제거하고 같은 마디의 뒤 음만 당긴다. 다음 마디의 소속은 유지한다. 마디에 쉼표 하나만 있었다면 빈 마디로 남긴다. 음표에서 Delete는 기존처럼 선택 음을 빈 박으로, 빈 박에서 Delete는 쉼표로 바꾼다.
