# 곡 음원 저장

곡 정보 수정에서 음원을 업로드하고 저장하면 기존 파일 저장소와 `workspace_documents`를 이용해 곡별로 관리합니다. DB 스키마 변경이나 마이그레이션 명령은 필요하지 않습니다.

- 파일: 기존 MediaAsset 및 설정된 Storage Provider 사용, 밴드 공개 범위.
- 곡 연결 정보: `song/<songId>/audio` 문서에 파일 ID, 이름, 음원 시작 시간(초)을 저장.
- 곡 정보 수정 권한이 있는 관리자만 연결 정보를 변경할 수 있습니다.
- 곡 정보 저장 전 취소하면 연결 정보는 변경하지 않습니다.
- 연결 해제·교체는 참조만 변경하며 원본 파일을 자동 삭제하지 않습니다.
- 곡 음원 설정에서 적용한 시작 시간은 곡 정보 수정 창의 저장을 눌러 서버에 반영합니다. PDF 뷰어는 곡 음원과 시작 시간을 기본으로 불러오며, 뷰어에서 임시 조정한 시간은 현재 뷰어에서만 유지합니다.
