# 개인 작업실

## 목적과 경계

개인 작업실은 특정 Band Workspace에 속하지 않는 사용자의 비공개 음악 도구 영역이다. 결과물은 기본적으로
본인만 볼 수 있으며, 사용자가 명시적으로 선택한 경우에만 Workspace의 자료 또는 악보로 복사한다.

초기 도구는 다음 두 가지다.

- **내 악기 추출**: 스피커 가까이에서 녹음한 합주 음원에서 가장 우세한 대상 악기만 분리
- **악보 편집**: 구조화된 음표·쉼표·코드·마디·파트를 직접 편집하고 재생·내보내기

## 내 악기 추출

사용자가 자신의 악기 Amp 또는 Speaker 가까이에 휴대폰을 두고 합주를 녹음하면 해당 악기가 다른
악기보다 우세하게 들어온다. 내 악기 추출은 이 우세도를 단서로 사용하고, 사용자가 선택한 Target
Instrument의 음색·주파수 특성을 함께 분석하여 해당 악기 Track 하나를 분리한다.

순간 Peak가 가장 큰 소리만 통과시키는 Volume Gate가 아니다. 예를 들어 Drum Hit가 순간적으로 더
크더라도 전체 구간에서 Guitar가 Target이면 Guitar의 연속성을 유지해야 한다.

- 모바일에서 바로 녹음하거나 기존 휴대폰 녹음 파일을 업로드한다.
- Guitar, Bass, Drums, Keyboard, Vocal, Other 중 Target을 자동 감지하고 사용자가 교정한다.
- 감지 결과에 악기별 우세도와 Clipping·Noise·Bleed 품질 경고를 표시한다.
- 원본, 추출본, 제거된 소리를 같은 Timeline에서 A/B 비교한다.
- 분리 강도, 주변 악기 억제, 음색 보존, Noise 감소를 조절하여 다시 처리할 수 있다.
- 추출 결과를 WAV·MP3로 내보내거나 개인 Practice Take로 저장한다.
- 원본 파일과 이전 결과는 덮어쓰지 않는다.

일반 Stem 분리는 원곡 Mix를 여러 악기 그룹으로 나누는 기능이다. 내 악기 추출은 근접 녹음 한 개에서
가장 우세한 Target Instrument 하나를 얻는 데 최적화한다. 녹음 위치, Room Reverb, Amp 왜곡, 다른
악기의 누음에 따라 완전한 분리가 불가능할 수 있으므로 결과 품질과 잔여 누음을 명확히 안내한다.

## 악보 편집

악보 편집기는 구조화된 Score 문서를 대상으로 한다. 새 악보를 만들거나 MusicXML을 가져오며, PDF와
이미지를 편집 가능한 악보로 자동 변환하지 않는다.

MVP 편집 범위:

- 파트, 오선, 마디 추가·삭제
- 음표, 쉼표, 음높이, 길이, 임시표, 타이, 아티큘레이션
- 코드 기호, 박자표, 조표, 템포, 반복 기호, 구간 Label
- 선택, 복사·붙여넣기, 실행 취소·다시 실행, 자동 저장, Revision 복원
- 기준 음원 연결, 재생 위치 Cursor, Metronome, 구간 Loop
- PDF와 MusicXML 내보내기, 인쇄용 미리보기
- 개인 악보를 선택한 Workspace의 자료로 복사

가사 자동 생성, PDF·이미지의 자동 악보 변환, 고급 조판 자동화, 실시간 공동 편집은 초기 범위에서
제외한다.

## 화면 구조

### 내 악기 소리로 악보 재생 (웹)

- 악보 상단의 `내 악기 소리로 재생`에서 WAV, MP3 등 단음 녹음을 올린다. 1~~3초 녹음을
  권장하며 최대 10MB, 0.15~~15초 파일을 허용한다. 합주나 코드 녹음은 자동 감지 대상이 아니다.
- 앞뒤 무음을 정리하고 음량을 맞춘 뒤 기준 음과 미세 조율을 감지한다. 감지 결과는 직접
  교정할 수 있으며 감지 실패 시 기준 음을 선택하거나 기본 음색으로 전환한다.
- `음색 미리 듣기`는 기준 음부터 장3도·완전5도·옥타브를 차례로 재생한다.
- 악보당 하나의 음색을 선택한 파트의 재생에 사용한다. 쉼표·코드·스타카토·강약과
  붙임줄·해머링·풀링·슬라이드를 기존 재생 경로에서 처리하며 뮤트는 짧은 타격음으로 재생한다.
- 기본은 녹음의 자연 감쇠를 유지한다. `긴 음 반복 유지`를 켜면 녹음의 중간 구간을 반복한다.
  피치 변환으로 샘플 재생 속도가 달라져도 악보의 음표 시작 시각과 박자는 바뀌지 않는다.
  반복 경계나 큰 음정 이동에서는 음색 변화가 들릴 수 있다.
- 녹음과 설정은 기존 개인 미디어 저장 경로로 자동 저장한다. 데모는 해당 브라우저에,
  로그인 환경은 계정의 비공개 첨부파일로 저장한다. MusicXML은 악보만 내보내며 녹음은 제외한다.

검증: `node --test scripts/instrument-sample.test.mjs scripts/mock-storage.test.mjs`
명령으로 음 감지, 음정·박자, 연결음, 중간 재생, 파일 검증과 첨부파일 복원을 확인한다.

### 내 악기 추출

- 상단: 프로젝트명, 휴대폰 녹음·파일 업로드, 처리 상태, 내보내기
- 중앙: 동기화된 원본·추출본 Waveform과 A/B 재생 Cursor
- Target: 자동 감지 악기, 사용자의 악기 교정, 악기별 우세도
- 측면: 분리 강도, 주변 악기 억제, 음색 보존, Noise 감소
- 결과: 원본·추출본·제거된 소리 비교, 품질 경고, Practice Take 저장

### 악보 편집

- 상단: 문서명, 저장 상태, 실행 취소·다시 실행, 내보내기, Workspace로 복사
- 도구 막대: 음표 길이, 쉼표, 임시표, 타이, 코드, 텍스트, 마디
- 좌측: 파트와 페이지·구간 탐색
- 중앙: 페이지 또는 연속 오선 편집 Canvas
- 우측: 선택 요소, 마디, 파트, 재생 속성 Inspector
- 하단: 기준 음원 Waveform, 재생, Metronome, Loop, 악보 Cursor

## 상태와 권한

- 개인 프로젝트의 Owner는 항상 생성한 사용자다.
- 공유 전에는 Workspace Member API와 분리된 개인 Scope로 저장한다.
- 추출 상태는 `UPLOADING`, `QUEUED`, `ANALYZING`, `SEPARATING`, `READY`, `FAILED`를 사용한다.
- 악보는 자동 저장하되 명시적인 Revision을 남겨 이전 상태를 복원할 수 있어야 한다.
- Workspace로 복사한 결과물은 개인 원본과 별도 Resource가 되며 이후 변경이 자동 동기화되지 않는다.
