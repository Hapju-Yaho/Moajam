# 개인 작업실

## 목적과 경계

개인 작업실은 특정 Band Workspace에 속하지 않는 사용자의 비공개 음악 도구 영역이다. 결과물은 기본적으로
본인만 볼 수 있으며, 사용자가 명시적으로 선택한 경우에만 Workspace의 자료 또는 악보로 복사한다.

초기 도구는 다음 두 가지다.

- **내 악기 추출**: 스피커 가까이에서 녹음한 합주 음원에서 가장 우세한 대상 악기만 분리
- **악보 편집**: 구조화된 음표·쉼표·코드·마디·파트를 직접 편집하고 재생·내보내기

## 내 악기 추출

사용자가 자신의 악기 Amp 또는 Speaker 가까이에 휴대폰을 두고 합주를 녹음하면 해당 악기가 다른
악기보다 우세하게 들어온다. 내 악기 추출은 이 우세도를 단서로 사용하고, 사용자가 선택한 Target
Instrument의 음색·주파수 특성을 함께 분석하여 해당 악기 Track 하나를 분리한다.

순간 Peak가 가장 큰 소리만 통과시키는 Volume Gate가 아니다. 예를 들어 Drum Hit가 순간적으로 더
크더라도 전체 구간에서 Guitar가 Target이면 Guitar의 연속성을 유지해야 한다.

- 모바일에서 바로 녹음하거나 기존 휴대폰 녹음 파일을 업로드한다.
- Guitar, Bass, Drums, Keyboard, Vocal, Other 중 Target을 자동 감지하고 사용자가 교정한다.
- 감지 결과에 악기별 우세도와 Clipping·Noise·Bleed 품질 경고를 표시한다.
- 원본, 추출본, 제거된 소리를 같은 Timeline에서 A/B 비교한다.
- 분리 강도, 주변 악기 억제, 음색 보존, Noise 감소를 조절하여 다시 처리할 수 있다.
- 추출 결과를 WAV·MP3로 내보내거나 개인 Practice Take로 저장한다.
- 원본 파일과 이전 결과는 덮어쓰지 않는다.

일반 Stem 분리는 원곡 Mix를 여러 악기 그룹으로 나누는 기능이다. 내 악기 추출은 근접 녹음 한 개에서
가장 우세한 Target Instrument 하나를 얻는 데 최적화한다. 녹음 위치, Room Reverb, Amp 왜곡, 다른
악기의 누음에 따라 완전한 분리가 불가능할 수 있으므로 결과 품질과 잔여 누음을 명확히 안내한다.

## 악보 편집

주법 적용 단위: 스타카토(S)는 선택한 박의 모든 음에 적용한다. 고스트노트(O, 약하게·괄호)와
데드노트(X, 뮤트)는 선택한 TAB 줄의 음에만 적용하며 두 효과는 해당 음에서 서로 배타적이다.
구간 선택 시에도 고스트·데드는 선택한 줄에 존재하는 음들만 수정한다. 빈 줄에서 X를 누르면
그 줄에 데드노트를 추가한다. 오선보에서는 누른 음높이로 대상 음을 선택한다.
다른 줄의 상태는 유지하며 복사·붙여넣기, 자동 저장, `.moajam`, MusicXML, PDF와 재생에도
구성음별 효과를 보존한다. 기존 박 단위 고스트·데드 악보는 이전 소리·모양을 유지한다.

악보 편집기는 구조화된 Score 문서를 대상으로 한다. 새 악보를 만들거나 MusicXML을 가져오며, PDF와
이미지를 편집 가능한 악보로 자동 변환하지 않는다.

MVP 편집 범위:

- 파트, 오선, 마디 추가·삭제
- 음표, 쉼표, 음높이, 길이, 임시표, 타이, 아티큘레이션
- 코드 기호, 박자표, 조표, 템포, 반복 기호, 구간 Label
- 선택, 복사·붙여넣기, 실행 취소·다시 실행, 자동 저장, Revision 복원
- 기준 음원 연결, 재생 위치 Cursor, Metronome, 구간 Loop
- PDF와 MusicXML 내보내기, 인쇄용 미리보기
- 개인 악보를 선택한 Workspace의 자료로 복사

가사 자동 생성, PDF·이미지의 자동 악보 변환, 고급 조판 자동화, 실시간 공동 편집은 초기 범위에서
제외한다.

## 화면 구조

### 악보 입력과 줄 배치 (웹)

- 프렛·음정 입력 시 현재 선택한 재생 악기 또는 내 녹음으로 해당 음을 짧게 들려준다.
  악보 재생 음량을 사용하며 연속 입력 시 이전 미리 듣기를 중단한다.
- 한 자리에서 Delete는 음표를 지운 뒤 빈 박 → 쉼표 → 빈 박으로 전환한다. 박 길이와
  뒤 음표 위치는 유지하며 TAB 화음에서는 선택한 줄의 음만 지운다.
- TAB에는 쉼표 기호를 그리지 않고 오선에만 표시한다. 세로 TAB 글자는 전체 현의 가운데에,
  마디 번호는 해당 마디 시작의 오선 바로 위에 정렬한다.
- 점음표 버튼과 `.` 키는 원래 길이의 절반을 더하거나 해제한다. 온음표부터 32분음표까지
  지원하며 뒤 음표와 코드 위치를 함께 이동해 겹침 없이 길이를 확보한다.
- 임시표는 같은 마디의 같은 음높이에 유지하며 필요할 때만 샵·제자리표를 표시한다.
  간격을 줄일 때 임시표 앞 공간을 우선 확보한다.
- 마디 우클릭 메뉴의 `이 줄의 마디 너비 균등하게`는 해당 줄에만 같은 너비를 적용한다.
  `이 줄의 마디 너비 자동 배분`으로 되돌릴 수 있다. 줄별 설정은 자동 저장·실행 취소와
  `.moajam` 파일에 포함하며 PDF에도 적용한다.

### 악보 재생 악기 (웹)

- 기본 악보 재생은 FluidR3의 녹음 음원을 사용한다. 파트별로 클래식·어쿠스틱·클린·오버드라이브
  기타, 어쿠스틱·핑거·피크·슬랩 베이스, 그랜드·일렉 피아노, 스트링, 합창, 신스 드럼 중 선택한다.
  신스 드럼은 음높이가 있는 단일 타악기 음색이며 GM 드럼 키트 매핑은 아니다.
- 악기 선택은 `Score.playbackInstruments`에 파트 이름별로 저장한다. 파트 이름 변경·삭제,
  자동 저장, 실행 취소·다시 실행과 `.moajam` 저장·불러오기에 반영한다. 기존 악보는 파트 이름과
  기보 악기에서 기본 음색을 정한다. 기보·튜닝 설정과 재생 음색 선택은 별개다.
- 악기 미리 듣기는 악보 음량으로 세 음을 재생하며 정지하거나 악기를 바꿀 수 있다.
  음원 준비 중 정지·화면 이동을 하면 늦게 완료된 로딩이 다시 재생을 시작하지 않는다.
- 가상악기 음원은 디코딩 시 각 음의 최대 진폭을 0.85로 맞춘다(최대 16배).
  좌우 채널에 같은 고정 배율을 적용해 파형·감쇠를 보존하며, 음량 0~100과 주법별 크기를 유지한다.
  사용자가 올린 녹음과 반주에는 이 음량 보정을 적용하지 않는다.
- 음원은 `apps/web/public/soundfonts/fluidr3`에 포함하며 선택한 악기의 필요한 음만 디코딩한다.
  출처·CC BY 3.0 안내와 고정된 원본 버전·해시는 함께 배포한다. 외부 스크립트를 실행하지 않는다.
  갱신은 `scripts/import-soundfonts.mjs`로 수행한다. 로딩 실패 시 오류를 표시하고 재시도할 수 있다.
- 사용자가 올린 녹음은 선택 기능으로 유지한다. 녹음 사용 중 가상악기를 선택하면 녹음 적용을
  해제하고 해당 파트의 악기로 전환한다. 녹음을 다시 선택하면 모든 파트에 적용한다.

### 내 악기 소리로 악보 재생 (웹)

- 악보 상단의 `내 악기 소리로 재생`에서 WAV, MP3 등 단음 녹음을 올린다. 1~~3초 녹음을
  권장하며 최대 10MB, 0.15~~15초 파일을 허용한다. 합주나 코드 녹음은 자동 감지 대상이 아니다.
- 앞뒤 무음을 정리하고 기준 음과 미세 조율을 감지한다. 원본 녹음과 채널을 보존하며
  재생할 때만 아래의 고정 배율로 음량을 높인다. 감지 결과는 직접
  교정할 수 있으며 감지 실패 시 기준 음을 선택하거나 기본 음색으로 전환한다.
  기준 음 감지는 실제 소리가 있는 구간을 분석하고 작은 감쇠음도 포함한다. 베이스의 배음이
  강해 옥타브 차이로 감지되는 경우 여러 구간에서 확인된 낮은 근음을 사용한다.
  무음·불안정한 음은 임의의 음으로 대체하지 않으며 직접 기준 음을 선택하도록 안내한다.
- `음색 미리 듣기`는 기준 음부터 장3도·완전5도·옥타브를 차례로 재생한다.
- `소리 출력 확인`은 녹음·기준 음·악보 음량과 독립적으로 선택한 가상악기 확인음을 두 번 재생한다.
  원본은 들리지만 선택 구간이나 악보만 들리지 않는 경우 `.moajam` 파일로 설정과 녹음을
  함께 보존해 재현한다.
- 악보와 반주 출력에는 볼륨 조절만 적용한다. 기존 32배 증폭, 리미터와 파형 변형은 적용하지 않는다.
  녹음 재생은 좌우 채널에 같은 고정 배율을 적용해 최대 2배 키운다. 선택 구간의 가장 큰
  절댓값이 0.85를 넘지 않도록 배율을 줄이며, 파형과 감쇠를 보존하고 음높이·길이·주법을 악보에 맞춘다.
  녹음 화음은 음 개수로 음량을 나누며 일반 음은 80%, 강세는 100%로 여유를 확보한다.
  구간 경계의 클릭을 줄이는 짧은 페이드와 기존 음소거 설정은 유지한다.
  기본 음색은 음 시작 직후 거의 무음으로 감쇠하지 않고, 음 길이의 80% 지점까지 초기 음량의
  60%를 유지한 뒤 끝에서 부드럽게 사라진다.
  `선택 구간 듣기`와 `음색 미리 듣기`에도 같은 녹음 배율을 적용한다.
  구간 옆의 `미리 듣기 볼륨`(0~100, 기본 100)은 선택 구간 재생에만 적용하며 재생 중에도
  즉시 조절할 수 있다. 0은 음소거이며, 100은 위의 녹음 배율을 적용한 최대 음량이다.
- 녹음 파형 안의 시작·끝 손잡이를 직접 끌거나 초 단위 숫자로 지정한다. 손잡이는 키보드
  방향키로 0.001초, Shift와 함께 0.01초씩 조절할 수 있다. 시간은 원본 녹음
  기준이며 최소 구간은 0.05초다. `선택 구간 듣기`는 지정 구간을 원래 높이로 한 번 재생하고,
  `전체 구간`으로 복원할 수 있다. 악보 재생·음색 미리 듣기·긴 음 반복은 모두 지정 구간을
  사용한다. 원본은 보존하고 구간 설정은 자동 저장과 `.moajam` 파일에 포함한다.
- 기준 음 자동 감지는 선택 구간이 바뀌면 다시 분석하고, 재생 직전에도 현재 구간의 음높이를
  사용한다. 직접 기준 음이나 센트를 지정하면 수동 모드로 전환한다. 기존 녹음 중 기준 음이
  없거나 MIDI 24 미만인 경우 자동 감지로 복구하여 극단적인 배속의 틱 소리를 방지한다.
  감지 실패 시 임의의 음높이를 사용하지 않고 실제 연주한 음을 지정하도록 안내한다.
- 악보당 하나의 음색을 선택한 파트의 재생에 사용한다. 쉼표·코드·스타카토·강약과
  붙임줄·해머링·풀링·슬라이드를 기존 재생 경로에서 처리하며 뮤트는 짧은 타격음으로 재생한다.
- 기본은 녹음의 자연 감쇠를 유지한다. `긴 음 반복 유지`를 켜면 녹음의 중간 구간을 반복한다.
  피치 변환으로 샘플 재생 속도가 달라져도 악보의 음표 시작 시각과 박자는 바뀌지 않는다.
  반복 경계나 큰 음정 이동에서는 음색 변화가 들릴 수 있다.
- 녹음과 설정은 기존 개인 미디어 저장 경로로 자동 저장한다. 데모는 해당 브라우저에,
  로그인 환경은 계정의 비공개 첨부파일로 저장한다. MusicXML은 악보만 내보내며 녹음은 제외한다.

검증: `node --test scripts/instrument-sample.test.mjs scripts/mock-storage.test.mjs`
명령으로 음 감지, 음정·박자, 연결음, 중간 재생, 파일 검증과 첨부파일 복원을 확인한다.

### 내 악기 추출

- 상단: 프로젝트명, 휴대폰 녹음·파일 업로드, 처리 상태, 내보내기
- 중앙: 동기화된 원본·추출본 Waveform과 A/B 재생 Cursor

- 측면: 분리 강도, 주변 악기 억제, 음색 보존, Noise 감소
- 결과: 원본·추출본·제거된 소리 비교, 품질 경고, Practice Take 저장

### 악보 편집

- 상단: 문서명, 저장 상태, 실행 취소·다시 실행, 내보내기, Workspace로 복사
- 도구 막대: 음표 길이, 쉼표, 임시표, 타이, 코드, 텍스트, 마디
- 좌측: 파트와 페이지·구간 탐색
- 중앙: 페이지 또는 연속 오선 편집 Canvas
- 우측: 선택 요소, 마디, 파트, 재생 속성 Inspector
- 하단: 기준 음원 Waveform, 재생, Metronome, Loop, 악보 Cursor

## 상태와 권한

### 웹 악보 파일과 PDF

- 상단 `파일로 저장`은 모든 파트, 악보 설정, 기준 음원과 악기 샘플을 `.moajam` 파일 하나에
  보관한다. 자동 저장과 별개인 이동 가능한 백업이며 다른 사람에게 전달하면 녹음도 함께 전달된다.
- `파일 불러오기`는 최대 160MB 파일을 검증하고 제목·파트·음표 수·첨부 여부를 보여준다.
  `이 악보 불러오기`를 누르면 현재 문서를 교체하며 자동 저장한다. 직전 문서와 녹음은
  `불러오기 전 작업으로 복원`으로 돌아갈 수 있다. 이 복원용 사본은 화면을 떠나면 사라진다.
- 잘못된 형식·버전·음표·연결·첨부 데이터를 거부하며 기존 악보는 그대로 유지한다.
- `PDF로 저장`은 현재 파트 또는 전체 파트를 A4 PDF로 직접 다운로드한다. TAB 포함 여부를
  선택할 수 있고, 각 파트는 새 페이지에서 시작한다. 긴 악보는 줄을 자르지 않고 여러 페이지로
  나누며 제목·파트·BPM·튜닝·페이지 번호를 표시한다. 화면 확대율이나 선택 표시를 포함하지 않는다.
- PDF는 고해상도 이미지로 악보 모양을 보존하며 최대 800마디를 한 번에 출력한다. PDF 자체는
  다시 편집할 수 없으므로 편집용 `.moajam` 파일을 함께 보관한다. MusicXML 가져오기·내보내기와
  브라우저 인쇄는 고급 설정에서 계속 제공한다.
- 검증: `node --test scripts/score-files.test.mjs` (왕복 복원, 첨부·형식 검증, PDF 악보·크기).

- 개인 프로젝트의 Owner는 항상 생성한 사용자다.
- 공유 전에는 Workspace Member API와 분리된 개인 Scope로 저장한다.
- 추출 상태는 `UPLOADING`, `QUEUED`, `ANALYZING`, `SEPARATING`, `READY`, `FAILED`를 사용한다.
- 악보는 자동 저장하되 명시적인 Revision을 남겨 이전 상태를 복원할 수 있어야 한다.
- Workspace로 복사한 결과물은 개인 원본과 별도 Resource가 되며 이후 변경이 자동 동기화되지 않는다.
