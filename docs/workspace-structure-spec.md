# 개인·밴드 워크스페이스 구조 기획

## 2026-10-23 적용: 참여곡 상세와 합주 도구 분리

아래의 기존 연습실 기획보다 이 절이 우선한다.

- 개인·밴드 메뉴의 연습실을 제거하고 독립된 합주 도구에 악보 편집과 사운드 트랙 편집을 배치한다.
- 참여곡 목록과 홈의 연습하기 버튼을 제거한다. 곡 클릭은 해당 밴드의 곡 상세로 이동한다.
- 곡 상세는 곡 의견 / 악보 보기 / 사운드 트랙 / 곡 정보·합주 기록으로 구성한다.
- 악보 보기에서는 PDF 추가·파트별 열람과 제작 악보의 적용본을 읽기 전용으로 제공한다.
- 사운드 트랙에서는 저장된 세션을 재생하고 시간별 피드백을 남긴다. 뮤트·솔로·음량·반복은 재생 중에만 적용하며 저장하지 않는다.
- 편집 버튼은 동일한 workspaceId와 songId를 합주 도구로 전달한다. 편집기에서 곡 상세의 해당 탭으로 돌아갈 수 있다.
- 악보의 버전 저장/적용, 개인 악보 비공개 저장, 밴드 악보 충돌 검사와 트랙 공유 기능은 유지한다. 저장 키나 기존 데이터를 이동하지 않는다.
- 새 웹 경로: `/tools`, `/tools/scores?workspaceId=…&songId=…`, `/tools/scores/personal`, `/tools/tracks?workspaceId=…&songId=…`.
- 기존 연습실 주소는 곡이 있으면 상세 트랙 탭을, 없으면 합주 도구를 표시한다. 기존 resources/practice/history 탭 링크도 새 구성으로 연결한다.
- PDF 미리보기와 제작 악보 렌더링은 웹에서 제공한다. 네이티브 앱은 기존의 악보 웹 지원 안내와 오디오 클립 재생을 유지한다.

범위: 화면 구성과 이동 방식에 대한 기획 및 프런트엔드 반영 기준.

## 프런트엔드 반영 상태

- 기존 앱에 개인 네 화면, 밴드 선택기, 밴드별 곡·멤버·합주 상태를 연결했다.
- 개인 홈·일정·참여 곡에서 원래 밴드와 해당 항목으로 이동한다. 개인 준비 상태는 밴드 채택곡에 반영된다.
- 웹에서는 밴드 상태와 마지막 선택 밴드를 브라우저에 저장한다. 서버 계정 간 동기화는 이번 범위에 포함하지 않는다.
- 웹 연습실은 로컬 트랙 업로드, 동시 재생, 음량·음소거·솔로, 구간 반복, 개인 녹음과 구간 메모를 제공한다.
  연습 트랙과 메모는 현재 탭에서 유지되며 녹음은 내려받아 보관한다. 모바일 네이티브 오디오는 별도 연결이 필요하다.
- 밴드 생성은 현재 프런트엔드 상태에 반영한다. 초대 링크를 통한 실제 계정 가입과 서버 권한 검증은 후속 연결 범위다.
- legacy 원본은 수정하지 않고, 화면 구성과 동작을 현재 공유 UI 구조에 맞춰 반영했다.

아래 내용은 목표 구조다. 위에 기재한 저장·오디오·초대 범위는 현재 구현의 한계로 구분한다.

## 핵심 방향

모아잼을 **내 음악 활동을 모아보는 개인 공간**과 **한 밴드가 함께 작업하는 밴드 공간**으로 구성한다.
한 사용자는 여러 밴드에 참여할 수 있고, 밴드별로 다른 파트와 역할을 가질 수 있다.

- 개인 공간: 내가 속한 모든 밴드의 일정과 연습할 곡을 한곳에서 확인한다.
- 밴드 공간: 선택한 밴드의 곡 추천, 채택, 연습 준비, 합주, 멤버를 관리한다.
- 개인 공간에서 보이는 밴드 일정과 곡은 밴드 데이터의 통합 조회다. 별도 사본을 만들지 않는다.

## 화면 채용 기준

| 공간 | 메뉴      | 채용할 화면      | 역할                                              |
| ---- | --------- | ---------------- | ------------------------------------------------- |
| 개인 | 홈        | legacy 홈        | 소속 밴드, 전체 일정, 다가오는 합주, 참여 곡 요약 |
| 개인 | 합주 일정 | legacy 합주 일정 | 모든 소속 밴드의 합주 캘린더                      |
| 개인 | 참여 곡   | legacy 참여 곡   | 모든 소속 밴드의 채택곡과 내 연습 상태            |
| 개인 | 연습실    | legacy 연습실    | 밴드와 곡을 선택해 개인 연습                      |
| 밴드 | 홈        | 기존 홈          | 선택한 밴드의 다음 합주와 팀 준비 상황            |
| 밴드 | 곡 추천   | 기존 곡 추천     | 추천, 의견 교환, 좋아요, 채택 후보 검토           |
| 밴드 | 채택곡    | 기존 채택곡      | 확정된 곡과 곡별 협업 공간                        |
| 밴드 | 합주      | 기존 합주        | 해당 밴드의 일정, 합주 기록, 결정사항             |
| 밴드 | 멤버      | 기존 멤버        | 해당 밴드의 멤버, 파트, 역할                      |

legacy의 별도 팀 상세 화면은 새 밴드 공간으로 대체한다. 용어는 화면 전반에서 ‘밴드’로 통일한다.
화면 구성은 위 출처를 따르고, 색상·버튼·서체 등 공통 표현은 현재 앱의 디자인 체계로 맞춘다.

## 사이드바

두 영역을 사이드바에 함께 노출해 개인 공간과 밴드 공간 사이를 바로 이동할 수 있게 한다.

```text
Moajam

개인 공간
  홈
  합주 일정
  참여 곡
  연습실

밴드 공간
  [주말 합주단             ▾]  ← 밴드 선택기
  홈
  곡 추천
  채택곡
  합주
  멤버

──────────────────────────
설정 · 도움말
내 프로필
```

개인 홈과 밴드 홈은 메뉴 이름이 같으므로 영역 제목, 활성 메뉴 표시, 본문 상단의 공간명을 함께 사용한다.
밴드 화면 상단에는 항상 현재 밴드 이름을 보여준다. 두 영역 중 실제로 열린 메뉴 하나만 활성화한다.

### 밴드 선택기

노션처럼 현재 밴드 이름을 누르면 참여 중인 밴드 목록이 열린다.

```text
밴드 변경
✓ 주말 합주단       기타 · 관리자
  일요일의 소음     베이스 · 멤버
──────────────────────────
+ 밴드 만들기
  초대 링크로 참여
```

- 밴드를 선택하면 선택한 밴드의 홈으로 이동한다.
- 개인 공간으로 이동해도 마지막 선택 밴드는 기억한다.
- 개인 공간의 통합 목록은 밴드 선택기의 선택에 영향받지 않는다. 목록 안의 밴드 필터로 좁힌다.
- 소속 밴드가 하나여도 선택기는 유지한다. 밴드 추가·참여 진입점으로 사용한다.
- 소속 밴드가 없으면 밴드 메뉴 대신 밴드 만들기·초대 링크로 참여를 안내한다.
- 모바일에서는 상단에서 개인/밴드 공간을 선택하고, 현재 공간에 맞는 하단 메뉴를 보여준다.

## 개인 공간 상세

### 홈

legacy의 ‘참여 중인 팀 + 캘린더 + 다가오는 합주 + 참여 곡’ 구성을 채용한다.

1. **내 밴드**: 밴드명, 멤버 수, 내 파트를 표시한다. 카드를 누르면 해당 밴드 홈으로 이동한다.
2. **전체 합주 캘린더**: 소속 밴드의 일정을 함께 표시한다. 밴드 이름과 색상으로 구분한다.
3. **다가오는 합주**: 가까운 일정부터 날짜·시간·장소·밴드를 보여준다.
4. **연습할 곡**: 참여 곡과 내 준비 상태를 보여주고 연습실로 연결한다.

개인 홈은 ‘내가 다음에 무엇을 준비해야 하는가’를 중심으로 구성한다.
밴드 전체의 추천 투표나 멤버별 준비도 상세는 밴드 홈에서 확인한다.

### 합주 일정

- 기본 범위는 모든 소속 밴드이며, 밴드별 필터를 제공한다.
- 캘린더에서 날짜를 선택하면 그날의 일정 목록을 확인한다.
- 일정에는 밴드명, 날짜, 시작·종료 시간, 장소를 표시한다.
- 일정 상세에서 해당 밴드의 합주 화면으로 이동할 수 있다.
- 개인 공간에서 일정을 등록할 때는 소속 밴드를 반드시 선택한다. 해당 밴드의 기존 권한 규칙을 따른다.

### 참여 곡

- 기본 목록은 **내가 속한 밴드의 채택곡 전체**다. 아직 채택되지 않은 추천곡은 제외한다.
- 곡명, 아티스트, 소속 밴드, 내 담당 파트, 내 준비 상태를 표시한다.
- 제목·아티스트 검색과 밴드별 필터를 제공한다. 담당 파트가 없는 곡은 ‘미배정’으로 표시한다.
- 같은 곡을 두 밴드에서 연주해도 두 항목으로 구분한다. 밴드별 편곡·자료·준비 상태가 다를 수 있다.
- ‘연습하기’는 개인 연습실로, 곡 상세는 해당 밴드의 곡 협업 공간으로 연결한다.
- legacy의 ‘곡 추가’는 밴드의 채택 절차에 맞춘다. 참여 곡 화면에서는 ‘곡 추천’으로 해당 밴드에 연결하고,
  직접 채택곡을 생성하지 않는다.

### 연습실

legacy의 곡 선택과 트랙 중심 연습 화면을 채용한다.

- 밴드와 곡을 선택해 재생, 트랙 조절, 녹음, 구간 연습을 진행한다.
- 곡 선택 항목에는 ‘곡명 · 아티스트 / 밴드명’을 표시한다.
- 참여 곡에서 들어오면 해당 밴드와 곡이 선택된 상태로 연다.
- 화면에는 현재 곡의 밴드명과 ‘밴드 곡 상세 보기’를 제공한다.
- 개인 연습 녹음은 기존 제품 기준대로 비공개 초안으로 시작한다. 명시적으로 공유한 녹음만 밴드에 공개한다.
- 밴드 곡의 ‘연습’ 진입점도 동일한 연습실 기능을 사용한다. 진입 위치와 돌아갈 위치만 구분한다.

기존 ‘내 악기 추출’과 ‘악보 편집’은 연습실 내부의 보조 도구로 배치하는 안을 제안한다.
개인 공간의 최상위 메뉴는 요청한 네 개로 유지하고, 개인 도구의 비공개 범위는 그대로 유지한다.

## 밴드 공간 상세

기존 화면의 기능을 유지하면서 모든 조회와 변경 범위를 **선택한 밴드 하나**로 제한한다.

| 메뉴    | 주요 구성                                                    |
| ------- | ------------------------------------------------------------ |
| 홈      | 다음 합주, 팀 준비도, 준비가 필요한 곡, 채택 후보, 최근 활동 |
| 곡 추천 | 추천 목록·상세, 좋아요, 의견, 채택 후보와 채택 처리          |
| 채택곡  | 확정된 곡 목록, 곡별 Overview·의견·자료·연습·합주 기록       |
| 합주    | 일정 생성·수정, 지난 합주, 녹음, 결정사항, 다음 체크리스트   |
| 멤버    | 멤버 목록, 초대, 파트 배정, 역할 관리                        |

곡 추천에서 채택된 곡은 해당 밴드의 채택곡과 개인 공간의 참여 곡에 함께 반영된다.
밴드별 역할과 권한은 독립적이다. 한 밴드의 관리자라고 다른 밴드에서도 관리자가 되는 것은 아니다.

## 이동과 데이터 원칙

| 출발           | 동작           | 도착                                       |
| -------------- | -------------- | ------------------------------------------ |
| 앱 첫 진입     | 기본 진입      | 개인 홈                                    |
| 개인 홈        | 밴드 카드 선택 | 해당 밴드 홈                               |
| 개인 합주 일정 | 밴드 합주 보기 | 해당 밴드 합주                             |
| 개인 참여 곡   | 곡 상세 선택   | 해당 밴드의 해당 곡                        |
| 개인 참여 곡   | 연습하기       | 해당 밴드·곡이 선택된 개인 연습실          |
| 밴드 곡 상세   | 연습하기       | 동일 곡의 연습실, 원래 곡 상세로 복귀 가능 |
| 밴드 선택기    | 다른 밴드 선택 | 새로 선택한 밴드 홈                        |

- 개인 통합 조회는 현재 소속된 밴드만 포함한다.
- 일정과 곡은 항상 원래 밴드의 식별자를 유지한다. 화면 이동만으로 소유 밴드를 바꾸지 않는다.
- 밴드를 바꾸면 곡·멤버·합주·권한도 함께 바뀐다. 이전 밴드의 상세 선택은 넘기지 않는다.
- 개인 공간에서 준비 상태를 바꾸면 해당 밴드 곡의 본인 준비 상태에 반영한다.
- 밴드 탈퇴나 곡 삭제로 접근할 수 없게 되면 이를 안내하고 접근 가능한 목록으로 돌아간다.
- 직접 링크는 링크에 포함된 밴드와 곡을 우선한다. 마지막 선택 밴드로 덮어쓰지 않는다.

권장 웹 경로는 개인 공간 `/me`, `/me/rehearsals`, `/me/songs`, `/me/practice`와
밴드 공간 `/workspaces/:workspaceId/...`로 구분한다.
연습 링크에는 `workspaceId`와 `songId`를 함께 담아 새로고침해도 선택한 곡을 복원한다.

## 구현 시 반영할 사항

현재 코드를 확인한 결과를 바탕으로 한 후속 구현 항목이다. 아직 구현된 기능을 뜻하지 않는다.

1. **공통 사이드바**: 고정된 ‘주말 합주단’ 표시를 실제 밴드 선택기로 바꾸고 개인 네 메뉴를 추가한다.
2. **라우팅**: 웹 이동 경로의 `ws-demo` 고정을 제거하고 현재 밴드 식별자를 전달한다.
3. **데이터 분리**: 현재 공통 목 상태를 밴드별로 분리하고, 개인 화면에는 소속 밴드 통합 조회를 제공한다.
4. **개인 화면 이식**: legacy의 네 화면 구성을 공유 앱 구조에 맞춰 이식한다.
5. **연습실 통합**: legacy의 브라우저 오디오 기능과 기존 곡 협업 화면을 연결한다.
   기존 비공개 녹음·공유 규칙을 적용하고 플랫폼별 오디오 구현은 분리한다.
6. **연결 검증**: 밴드 전환, 개인 통합 조회, 특정 곡 이동, 뒤로 가기, 새로고침을 확인한다.

legacy는 웹 DOM 기반이고 현재 앱은 웹·모바일 공유 구조이므로, 파일을 그대로 옮기기보다
화면 구성과 동작을 채용하고 플랫폼 의존 기능을 분리하는 방향으로 진행한다.

## 완료 기준

- 서로 다른 두 밴드의 일정과 채택곡이 개인 공간에서 함께 보인다.
- 밴드 필터와 밴드 선택기가 각자의 범위에만 영향을 준다.
- 밴드를 바꾸면 밴드의 다섯 메뉴가 모두 해당 밴드 데이터로 바뀐다.
- 같은 제목의 곡이라도 밴드별 자료·준비 상태·녹음이 섞이지 않는다.
- 개인 참여 곡에서 고른 밴드와 곡이 연습실에서도 유지된다.
- 밴드가 없거나 일정·곡이 비어 있어도 다음 행동을 안내한다.
- 모바일에서도 개인 공간 이동과 밴드 변경이 가능하다.
