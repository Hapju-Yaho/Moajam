# 가사 구분절 타이밍과 현재 가사 따라가기

가사 보기 상단의 `가사 편집`에서 빈 줄 하나(줄바꿈 두 번)로 구분절을 나눕니다. 한 구분절 안의 줄바꿈은 유지합니다. `가사 편집` 오른쪽의 `가사 박자 설정`에서 입력하고, 하단 `자동 스크롤` 왼쪽의 `가사 따라가기`로 결과를 봅니다.

1. 악보 화면과 독립된 가사 화면에서 메트로놈으로 BPM·박자를 지정합니다. 상단에는 처음으로, 재생, 메트로놈, BPM, 박자 순으로 표시하고 박자 저장은 오른쪽에 둡니다.
2. `가사 박자 설정`에서는 박자 입력이 항상 활성화됩니다. 재생을 누르면 BPM 기준 4박 동안 4 → 3 → 2 → 1을 표시한 뒤 현재 위치부터 재생합니다. 카운트 중에는 박자를 기록하지 않습니다. Space는 재생·일시 정지이며 카운트 중에는 취소합니다.
3. 구분절이 시작할 때 Enter를 누릅니다. 재생 위치를 가장 가까운 8분음표(4분음표 기준 0.5박)로 보정합니다. 전체 가사는 목록에 유지하고 마지막으로 기록한 가사를 주황색으로 강조하며 오른쪽에 마디·박을 표시합니다.
4. `마지막 입력 취소`, `초기화`, `다시 입력`으로 수정하고 `박자 저장`을 누릅니다.
5. 저장 후 상단의 `가사 박자 설정`을 닫고 하단의 `가사 따라가기`를 켭니다. 저장된 재생 기준으로 재생을 시작하며 현재 구분절을 강조하고 가사 영역 중앙으로 부드럽게 이동합니다. 첫·마지막 구분절도 중앙에 배치할 수 있도록 여백을 둡니다. 각 구분절은 다음 구분절 시작까지, 마지막 구분절은 재생이 끝날 때까지 유지됩니다. 첫 구분절 전에는 강조하지 않습니다. 자동 스크롤과 가사 따라가기는 동시에 켜지지 않습니다.

가사 화면에서는 악보 프로젝트를 조회하거나 악보 편집기를 열지 않습니다. 기존 악보 편집 화면의 열림 상태와도 독립적이며, 현재 박자 설정에서는 YouTube를 재생 기준으로 사용하지 않습니다.

## 저장과 배포

- 기존 가사 원문 `song/{songId}/lyrics`는 그대로 유지합니다.
- `song/{songId}/lyrics-timing` 워크스페이스 문서에 원문 스냅샷, 마지막 재생 기준, 재생 기준별 BPM·박자·구분절 시작 박을 저장합니다. 메트로놈과 YouTube 영상 ID별로 구분합니다. 이전 버전의 악보 프로젝트 기준 타이밍 데이터는 삭제하지 않지만 자동으로 열지 않습니다.
- 가사 원문이 바뀌면 이전 타이밍을 자동 적용하지 않습니다. 개인 연습 화면과 밴드 화면은 같은 곡의 타이밍을 사용하며, 기존 개인/밴드 글자 크기·스크롤 속도 설정의 구분은 유지합니다.
- 최대 50개 재생 기준, 기준별 3,000개 구분절을 지원합니다. 서버는 순서·8분음표 격자·원문 구분절 범위 등을 검증합니다.
- **DB 테이블·컬럼 변경과 마이그레이션은 없습니다.** 기존 워크스페이스 문서 저장소를 사용합니다. 서버의 새 문서 키 허용·검증 코드를 웹과 함께 배포하고 서버를 재시작해야 합니다. 이전 서버는 새 키 저장을 허용하지 않습니다.
- 테스트에서는 YouTube·오디오 재생을 모의 처리합니다. 실제 외부 영상의 재생 허용 여부와 네트워크 환경은 별도로 확인해야 합니다.
